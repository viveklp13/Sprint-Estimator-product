✅ Fields Auto-Derived From Jira Export

  • Project Name — Project key or Project name column
  • Feature Name — Epic Link or Epic Name for Story rows
  • Feature Start/End Date — MIN / MAX of child Story Created / Due dates
  • Is Completed — Status ∈ {Done, Closed, Resolved} → TRUE
  • Story Hours (Est) — Original Estimate converted from seconds to hours (÷ 3600)
  • Story Hours (Actual) — Time Spent converted from seconds to hours (÷ 3600)
  • Story Start Date (Act) — Updated date when status first moved to In Progress
  • Story End Date (Act) — Resolved date from the Jira export

📖 How to Export from Jira

Step 1 — Navigate to Issues

In your Jira project, go to Issues in the left sidebar (or top menu). For Jira Software use Backlog or the Board view.

Step 2 — Create a Filter / Advanced Search

Click Advanced to switch to JQL and enter a query to capture all issue types you need:

project = "YOUR_PROJECT_KEY"
AND issuetype in (Epic, Story, Bug)
AND sprint in openSprints()
ORDER BY issuetype ASC, created ASC

Replace YOUR_PROJECT_KEY with your actual Jira project key (e.g. EC, MOBI, etc.)

Step 3 — Export to CSV

Click the Export button (top-right of the issue list) and choose one of:

  • Export Excel CSV (all fields) — recommended; includes all custom fields
  • Export CSV (current fields) — only exports visible columns; add required fields first
💡 Tip: Use Export Excel CSV (all fields) to ensure Original Estimate, Time Spent, Epic Link and Epic Name are included.

Step 5 — Understanding the Epic ↔ Story Link

Jira exports a flat list. Stories are linked to their parent Epic via:

  • Epic Link column contains the parent Epic key (e.g. EC-1) for each Story row
  • Epic Name column contains the readable Epic title — used as the Sprint Estimator Feature Name
  • If Epic Name is blank, the converter falls back to looking up the Epic row by Epic Link key and using its Summary
  • In Next-gen projects, the parent link is in the Parent column instead

Step 6 — Get Defect Counts (SIT / UAT)

Run separate JQL queries to count SIT and UAT bugs per Epic/Sprint:

issuetype = Bug AND labels = "SIT" AND project = "YOUR_PROJECT_KEY"
→ count = SIT Defects

issuetype = Bug AND labels = "UAT" AND project = "YOUR_PROJECT_KEY"
→ count = UAT Defects

Add these counts manually in the Sprint Estimator Productivity Tracker after import.

Step 7 — Time Field Note (Seconds vs Hours)

Jira stores Original Estimate and Time Spent as seconds in the CSV export:

16 hours → 57600 seconds (16 × 3600)
8 hours → 28800 seconds ( 8 × 3600)

The converter automatically divides by 3600 to convert to hours. If your export already shows hours (some Jira configurations), disable this via the Time unit toggle in the converter.

Step 8 — Upload to Sprint Estimator

Use the 🔄 Live Converter tab to convert your Jira CSV to Sprint Estimator format, then upload via 📊 Import Excel → Upload & Import in Sprint Estimator V4.
